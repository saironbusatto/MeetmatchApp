# Farmei · Marketing site

Long-form marketing page: nav, hero, how-it-works, features grid, pricing, closing CTA, footer.

## Files

- `index.html` — full page
- `components.jsx` — nav, footer, button (StampButton), logomark, wordmark, sparkle
- `sections.jsx` — Hero, HowItWorks, Features, Pricing, ClosingCTA

## Notes

- The signature **stamp shadow** (flat ink offset, no blur) carries through every CTA and feature card. It's the most consistent expression of the brand.
- The hero uses a tilted **AI suggestion card** as the lead visual rather than a screenshot — it doubles as the product proof and the brand mark.
- Two colored full-bleed moments: vermillion in the closing CTA, ink in the feature spotlight. Spark yellow is only used inside cards and chips.
- Type pairs: Bricolage for every heading (-2% to -3.8% tracking), Geist for body, JetBrains Mono for the dates inside the hero card and step numbers.
